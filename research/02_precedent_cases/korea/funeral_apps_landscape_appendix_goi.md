## 0. 한 줄 결론 먼저

**고이상조는 "장례 디지털화"가 아니라 "장례 산업의 신뢰 구조 재설계"를 팔고 있다.** 정찰제·후불제·100% 환불은 표면이고, 본질은 **"이 산업의 종사자들이 그동안 안 한 일을 우리가 한다"는 도덕적 차별화**다. 도구가 아니라 입장으로 이긴다는 게 다른 5개 앱과의 가장 큰 차이다. 그리고 이 입장을 받아주는 30~40대 사전 가입자라는 코호트가 존재한다는 사실 자체가, 인구구조 보고서에서 예측한 "장례 경제 주체의 이동"이 이미 시작되었다는 가장 강한 시장 신호다.

## 1. 브랜드 포지셔닝 — 왜 이 메시지가 먹히는가

### 1-1. 메인 슬로건의 구조

고이상조의 메인 카피는 **"숨김없는 장례의 시작, 고이"**다. 이 한 줄에 세 가지 의도가 압축되어 있다.

- **"숨김없는":** 기존 업계의 가격·품목 불투명성을 적으로 규정한다. 적이 명확하면 입장이 선명해진다.
- **"장례의 시작":** 부고 발생 직후 → "어디부터 해야 하지"라는 막막함을 잡는 진입점 위치 선언.
- **"고이":** "고이 모시다"의 어감. 동사적 의미와 이름이 한 단어 안에 들어 있다.

### 1-2. 회사소개 페이지의 핵심 문장

> "고이의 사명은 상주님이 고인을 애도하는 일에만 집중하도록 돕는 것입니다."

이 한 문장이 제품·가격·운영 모든 의사결정의 상위 원칙으로 작동한다.

### 1-3. 세 가지 약속 (홈페이지 핵심 영역)

회사소개 페이지에 큼지막하게 박혀 있는 세 약속은 메인 페이지·상품 페이지에도 반복 노출된다 — 단순 광고문구가 아니라 사실상 회사의 헌법이다.

| 약속 | 내용 | 적으로 규정한 업계 관행 |
|---|---|---|
| **품목별 가격 정찰제** | 모든 품목에 정가 표시, 실제 사용 품목만 청구 | "패키지 묶음" 후 임의 추가 청구 |
| **사용하지 않은 품목 100% 공제** | 명시 금액만큼 현금 환불 | "권리 포기로 간주", "다른 품목으로 대체" |
| **서비스 불만족시 100% 환불** | 강매·노잣돈·수고비 일체 금지, 적발 시 전액 환불 | 현장 수고비 관행, 식장 내 끼워팔기 |

원장님이 인터뷰에서 토로하신 "고비용 저효율 → 저비용 고효율로 바꾸는 새로운 상조" 슬로건과 정확히 같은 좌표다. 즉 원장님이 채영에게 권하신 방향성을 **고이가 이미 전국 단위로 구현하고 있다**는 사실을 직시할 필요가 있다.

## 2. 메인 보고서와 동일한 6항목 분석

### ① 주요 기능

웹페이지를 6개의 사용자 흐름으로 분해하면 다음과 같다.

**(a) 견적 신청 흐름 (`/match/request/`)**
- 시/도 선택 → 조문객 수 → 긴급도(급하지 않음 ~ 임종 상태) 선택 → 추천 견적
- "비용을 미리 알아본 사람들은 평균 246만원을 아낀다"는 주력 메시지

**(b) 상품 구매 흐름 (`/product/`)**
- 패키지 즉시 가입(고이패키지) / 월 납입(고이 프라임) / 계약금 상품(고이 퍼스트) 3트랙
- 각 트랙 하위에 무빈소장·가족장·일반장 3옵션

**(c) 임종 접수 (24시간 고객센터)**
- 1666-9784 / 카카오톡 채팅 채널(`@xgFDaK`)
- 카카오톡 채널이 정식 진입 동선의 한 축으로 설계됨

**(d) 장례 절차 가이드 (`/guidebook/`)**
- 처음 장례를 치르는 사람을 위한 정보 콘텐츠

**(e) 후기 시스템 (`/review/`)**
- 카테고리: 따듯하고 능숙한 장례지도사 / 해외 거주민 / 종교 장례 / 이미 가입된 상조가 있는 경우
- 실명 후기, 지도사 이름까지 노출 (예: "김유성 지도사님", "신정훈 장례지도사님")

**(f) 상담사 조회 (`/consultant/search/`)**
- 70명 검증 지도사를 사용자가 직접 조회 가능
- 익명 상담사가 아니라 "이 사람"이라는 인격이 살아 있음

### ② 타겟 고객

웹사이트 진입 동선에서 4가지 사용자 페르소나가 명확히 분리되어 있다.

| 사용자 상황 | 진입 동선 | 추천 상품 |
|---|---|---|
| 급하지 않지만 미리 알아보려는 사람 | 견적 → 100원 상조 / 고이 퍼스트 | 사전 가입 트랙 |
| 1주~1개월 남은 임종 예정 | 견적 → 즉시 가입 가능 패키지 | 고이 패키지 |
| 임종 며칠 남지 않음 | 24시간 고객센터 직접 연결 | 임종 접수 |
| 임종 상태 | 임종 접수 채널 | 즉시 출동 |

특히 **"이미 가입된 상조가 있는 경우"라는 후기 카테고리가 별도로 있다는 점**은, 고이가 기존 상조 가입자를 **갈아타기 시키려는 의도**를 명시적으로 갖고 있다는 뜻이다. 이는 일반적인 상조 마케팅의 신규 가입 일변도 메시지와 다르다.

연령 구성에서 핵심 사실: **100원 상조 가입자의 상당수가 30~40대**라고 송슬옹 대표 인터뷰에 명시되어 있다. 채영의 인구구조 보고서가 예측한 "사전 준비 시장의 30~40대 코호트 진입"이 실제 데이터로 확인되는 지점이다.

### ③ 수익 모델

표면적으로 단순하지만, 실제 구조는 4중이다.

**(a) 후불제 장례 매출 (코어)**
- 가족장 289 / 일반장 389 / 무빈소장 159만원대 패키지
- 정찰제로 청구, 미사용 품목 환불
- 39,574건 누적 (회사소개 페이지 기준) → "후불제 상조 브랜드 1위"

**(b) 사전 가입 결제 (Pre-Need)**
- 고이 프라임(월 100원 × 300개월): 가입 시점 가격 평생 보장
- 고이 퍼스트3 (3만원 일시): 평생 보장 + 차액 후불
- 고이 퍼스트10 (10만원 일시): 평생 보장 + 추가 10만원 할인 → 가족장 289가 279만원으로

**(c) 장지·납골당 송객 매출 (추정)**
- "장례식장, 장지 추천부터" 메인 메시지에 포함
- 첫장과 동일하게 송객 수수료가 발생할 가능성

**(d) 부가 매출**
- 위패(memorial table) 별도 배너로 노출 → 단품 판매
- 후기 페이지의 "근조화환" 동선

핵심 차별점: **선불식 상조의 락인(lock-in) 모델을 선택하지 않았다**는 점이다. 일반 상조는 수백만 원의 선납으로 가입자를 묶는데, 고이는 100원만 받는다. 가입자의 협상력을 의도적으로 보존하는 설계 — 그러면서도 가입 시점 가격을 평생 보장해 줌으로써 **"미래 가격 인상에서 보호"**라는 가치를 판다.

### ④ 특이점

**(a) "비-앱 전략"** — 이미 본 보고서에서 다룬 핵심. 모바일 앱 없음. 24시간 고객센터(전화 + 카카오톡 채널)가 진입점.

**(b) 70명만 선발한 장례지도사 네트워크**
- 4단계 검증: 서류 → 인터뷰 → 레퍼런스 → 현장 서비스 검증
- 전국 70명. 평균 평점 4.9 / 5.0
- **소규모 정예 네트워크 = 품질 통제의 핵심**
- 지도사 이름이 후기에 직접 등장 → 기존 상조의 "익명성"을 깬다

**(c) 흑자 달성 시점 공개**
- 2023.11 BEP 달성 — 자랑이 아니라 신뢰 자산으로 사용
- 누적 119억 투자, 자본금 119억 — 신뢰 자산 패널에 노출

**(d) 카카오톡 채널을 정식 진입 동선으로 채택**
- `pf.kakao.com/_xgFDaK/chat` — 한국인 사용자의 일상 채널을 그대로 채택
- 앱 설치 부담 없음 + 24시간 응답 가능 = 비-앱 전략의 핵심 무기

**(e) 후기의 "지도사 이름" 노출**
- 김유성, 신정훈, 황경하, 최서규 등 실명
- "다음에 우리 가족 갈 때도 이분 부탁한다"는 후기가 그대로 노출됨
- 이건 단순 후기 운영이 아니라 **지도사 개인 브랜드를 회사가 키우는 전략**

**(f) 공정위 선불식 할부거래업 등록 (2024.05)**
- 100원 상조 출시 1년 후 제도권 진입
- 스타트업이 규제 회피가 아니라 규제 안으로 들어가는 선택을 한 것

### ⑤ 사용자 반응 — 후기에서 반복되는 패턴

회사소개 페이지에 노출된 실명 후기 3건과 메인 페이지 후기 카테고리에서 반복되는 단어를 추리면 다음 패턴이 보인다.

**가장 자주 등장하는 표현:**
- "정성껏" / "꼼꼼히" / "세심하게"
- "장례지도사님 덕분에"
- "다음에 우리 어머니/아버지 모실 때도 부탁드리고 싶다"
- "친척들이 명함 요청"

**드러나는 사용자 심리:**
- 첫 장례인 가족이 다수 (30~50대 자녀)
- "여러 군데 비교 후 고이 선택"이 후기 빈출 패턴 — 가격 비교가 일상화됨
- 장례지도사 개인에게 강한 애착 형성 — 다음 장례에도 같은 사람을 원함
- "엄마/아빠가 만족하셨다"는 표현 자주 등장 — 효(孝)의 프레임이 살아 있음

**특기할 후기 (39세 여성 김OO님):**
"상조를 미리 알아보는게 오빠의 긴 여행을 독촉하는건 아닐까 망설였지만, 막상 일이 닥쳤을 때 허둥지둥 하기보다는 오빠가 여행가는 먼 길 헤매지 않도록 경황없을 부모님 대신 제가 알아보고 가입했어요."

→ **사전 가입자의 심리적 망설임("미리 준비한다는 죄책감")과 그것을 넘어선 합리화 과정**이 그대로 드러난다. 이게 30~40대 사전 가입의 정서적 구조다. 채영이 영업 메시지를 만들 때 직접 참고할 만한 1차 자료다.

### ⑥ 채영의 관점에서의 시사점

**(a) 정찰제·후불제·맞춤형은 이미 표준이 되고 있다.**
원장님이 권하신 슬로건의 핵심 요소를 고이가 전국 단위로 선점한 상태. 채영이 같은 슬로건을 들고 들어간다면 **"제주 지역의 고이"라는 포지션**이 가장 자연스럽다 — 큰 그림은 같지만 지역과 관계 자산으로 차별화한다.

**(b) 70명 정예 네트워크 모델의 함의.**
고이는 의전을 외주 회사로 통째로 넘기지 않는다. 자체 검증한 70명을 직접 운용한다. 채영의 진입로(원장님이 말씀하신 "서울 의전팀과 65~70:30~35 배분")는 이 모델의 정반대 — 외주에 의존한다. 이게 단기 현금흐름에는 유리하나, **장기 관점에서 채영 본인의 "지도사 자산"이 쌓이지 않는 구조**라는 점은 직시해야 한다. 영업·중개를 시작하더라도 일정 시점부터는 검증된 지도사를 자기 진영에 묶는 작업을 시작해야 한다.

**(c) 비-앱 전략은 자본 0원 진입에 유리하다.**
고이가 앱 개발에 자본을 쓰지 않고 카카오톡 채널 + 웹 + 24시간 콜로 운영한다는 사실은, 채영이 영업 단계에서 자체 도구로 (i) 카카오톡 비즈니스 채널 + (ii) 가격표 PDF + (iii) 후기 모음 페이지(노션 또는 단순 웹사이트) 정도로 충분히 시작 가능하다는 뜻이다.

**(d) 30~40대 사전 가입 시장이 실제로 작동한다.**
인구구조 보고서의 가설이 고이의 100원 상조 가입자 데이터로 1차 검증됨. 채영이 만약 본인 명의 사전 설계 영역으로 진입한다면, 이 코호트의 망설임-합리화 패턴(위 후기 인용)을 메시지의 출발점으로 사용 가능.

## 3. 상품 구조 분해 — 가격 결정 트리

고이의 상품 페이지를 구조 분해하면 **장례 시점 × 결제 시점**이라는 두 축의 매트릭스가 된다.

### 3-1. 두 축의 매트릭스

```
                  결제 시점 →

                 즉시 결제          미리 결제
              ┌──────────────┬──────────────┐
              │              │              │
   장례  즉시 │  고이 패키지  │  (해당 없음) │
              │  (당일 가입,  │              │
              │   당일 사용)  │              │
              │              │              │
   장례  ─────┼──────────────┼──────────────┤
              │              │              │
   장례 미래 │  (불가)      │ 고이 프라임  │
              │              │ 고이 퍼스트  │
              │              │              │
              └──────────────┴──────────────┘
```

### 3-2. 패키지별 가격 (만원)

| 패키지 | 무빈소장 | 가족장 | 일반장 |
|---|---|---|---|
| 즉시 패키지 가격 | 159 | 289 | 389 |
| 고이 프라임 (월 100원 × 300개월 적립 후 차액 후불) | 159 - 30 = 129 | 289 - 30 = 259 | 389 - 30 = 359 |
| 고이 퍼스트3 (3만원 일시 + 차액 후불) | 159 - 3 = 156 | 289 - 3 = 286 | 389 - 3 = 386 |
| 고이 퍼스트10 (10만원 일시 + 추가 10만원 할인) | - | **289 - 10 - 10 = 269** | - |

### 3-3. 주목할 설계 의도

**(a) "고이 퍼스트10"이 가장 공격적인 미끼.**
10만원 일시 결제로 가족장 289만 원짜리가 269만 원이 된다. 즉 "오늘 10만원 내고 미래 가격을 봉인하면 20만원 이득"이라는 명확한 손익 계산이 가능하다. **가입을 망설이는 30~40대를 끌어들이는 결정적 미끼**.

**(b) "고이 프라임"의 25년 약정은 사실상 약정이 아니다.**
월 100원 × 300개월 = 30,000원. 25년을 100원씩 내면 누적 3만원. **이건 "약정"이 아니라 "리마인더 구독"**에 가깝다. 매달 100원이 빠져나가면서 가입자는 매달 자기가 가입했다는 사실을 잊지 않게 된다. 그리고 가입 시점 가격이 평생 보장된다.

**(c) "정찰제 + 미사용 품목 100% 환불"의 결합 효과.**
이 두 정책이 결합되면 사용자에게 "최대 손실은 정해져 있고, 최선의 경우엔 더 적게 낼 수도 있다"는 비대칭적 보상 구조가 생긴다. 행동경제학적으로 설계된 가격 정책이다.

## 4. 운영 인프라 — "70명 모델"의 분해

### 4-1. 검증 4단계

```
1단계: 서류 전형
   └ 자격증, 경력 증명, 결격 사유 확인

2단계: 인터뷰
   └ "장례지도사는 직업이 아닌 소명" 등 가치관 검증

3단계: 레퍼런스 체크
   └ 이전 근무지·동료·고객 평판 확인

4단계: 현장 서비스 검증
   └ 실제 의전 동행 모니터링
```

### 4-2. 이 모델의 경쟁 우위

**(a) 품질 분산이 적다.**
일반 상조는 외주 의전팀과 계약 → 의전팀 내부의 누가 배정되는지 통제 못함 → 사용자 경험 분산이 큼. 고이는 70명 풀 안에서만 배정 → 분산 작음.

**(b) 후기에 이름이 살아남는다.**
"황경하 지도사", "김유성 지도사", "신정훈 지도사" — 실명이 후기에 살아남는 이유는 **사용자가 지목할 수 있다**는 사실 덕분이다. 70명 풀이라서 가능한 일.

**(c) 공급 측 락인.**
지도사 입장에서 고이를 떠나면 자기 후기·고객 자산을 잃는다. 고이는 지도사 개인 브랜드를 키워줌으로써 지도사를 묶는다. 일반 상조의 "이름 없는 의전팀" 모델과 정반대.

### 4-3. 이 모델의 약점

**(a) 확장성 한계.**
70명으로 전국 39,574건을 처리한다는 건 1인당 연 평균 565건 — 사실상 불가능한 숫자. 공개 데이터만으로는 풀 사이즈 vs 누적 건수의 시점 차이가 정리되지 않는다. 풀이 70명 그대로라면 동시 다발 의전 발생 시 적체가 생길 수 있다.

**(b) 지역 편중.**
서울·수도권 중심으로 추정. 지방 출장의 거리·시간 비용이 모델의 약점일 수 있음. **이게 채영의 제주 진입 여지의 근거가 된다** — 고이의 70명 안에 제주 지도사가 몇 명인지(또는 0명인지)가 결정적 변수.

**(c) 70명 검증 시스템의 비용.**
4단계 검증은 영업 비용이 크다. 신규 지도사 1명을 들이는 데 수개월 소요 가능. 시장 확장 속도의 천장이 여기에 있다.

## 6. "비-앱 전략"의 의미를 다시 본다

### 6-1. 본 보고서 8장의 가설을 검증한다

본 보고서 8장에서 세웠던 세 가지 가설:
- (a) 사용자 행태 가설: 검색→비교→견적의 흐름이 길어 모바일 브라우저+상담원이 더 자연스럽다
- (b) 자본 효율 가설: 앱 개발/유지보다 웹+광고 ROI가 좋다
- (c) 의도된 무앱 가설: 평소 잊고 있다가 필요할 때만 찾는 서비스의 정서

웹사이트 분석 결과, **세 가설이 모두 부분적으로 맞다**고 결론 내릴 수 있다.

**(a)는 견적 신청 흐름이 5~6단계인 점에서 확인된다.** 시/도 선택, 조문객 수, 긴급도, 연락처 입력, 상담사 콜백, 상담 진행 — 이 흐름은 앱 화면 UI보다 웹 페이지 + 상담원 + 카카오톡 채널의 조합이 자연스럽다.

**(b)는 앱 개발·유지·플랫폼 수수료를 고려하면 자명하다.** 카카오톡 채널은 무료에 가깝고, 일반 웹은 SEO 트래픽으로 들어온다. 119억 자본을 받았어도 앱에 돈을 쓰지 않은 결정은 의도된 것으로 보인다.

**(c)도 맞다.** 100원 상조 가입자가 매일 앱을 열 이유가 없다. 자동 결제 알림(매월 100원 빠지는 SMS)이 사실상의 리마인더 역할을 한다.

### 6-2. 그러나 이 전략이 영원하지는 않다

고이의 비-앱 전략에는 약점도 있다.

**(a) 모바일 OS 알림 자산이 없다.**
앱이 없으니 푸시 알림을 보낼 수 없다. SMS·카카오톡에 의존. 마케팅 메시지의 도달률 통제가 떨어진다.

**(b) 데이터 수집이 얕다.**
앱은 사용자의 행동 패턴(언제 열어보는지, 어디까지 스크롤하는지)을 정밀하게 수집한다. 웹은 이 깊이의 데이터를 만들기 어렵다.

**(c) 채영의 스마트워치 트리거 플랫폼 같은 영역은 앱 우선이다.**
재택임종 감지·검안의 매칭은 본질적으로 모바일 앱 영역이다. 고이가 이 영역으로 확장하려면 결국 앱을 만들어야 한다 — 즉 고이의 비-앱 전략은 **현재 사업 범위에 한정된 의도된 선택**이지 만능 전략은 아니다.

## 8. 채영의 진입 전략에 주는 함의 (3가지 트레이드오프)

### 8-1. "고이의 그림자 안에 들어간다" 옵션

채영이 **고이의 70명 지도사 풀에 합류**한다. 영업·중개가 아니라 운영 지도사로 직접 진입.

- 장점: 검증된 시스템, 안정적 매출, 브랜드 후광. 자본 0원 진입에 가장 안전.
- 단점: 채영의 사업적 자율성 사라짐. 70명 풀의 한 명으로 종속. 플랫폼 지배력이라는 장기 목표와 정반대 방향.
- 채영의 결정 영역: **이건 사실상 취업 모델이고, 채영이 거부한 경로다.** 단 본인 의지보다 가족 환경(아내의 사업 우려)이 더 강해질 경우 대안으로 검토 가능.

### 8-2. "고이가 닿지 않는 영역에서 시작한다" 옵션 (현재 진입로의 정통)

채영이 **제주에서 영업·중개 모델로 시작**한다. 원장님이 권하신 그대로.

- 장점: 고이가 들어오지 못한 시장 공백. 채영의 거주지 강점. 자본 0원 진입.
- 단점: 서울 의전팀 의존. 65~70:30~35 마진의 상한선. 제주 지역 시장 자체의 작은 규모.
- 채영의 결정 영역: **현재 합의된 1순위 진입로.** 단, 영업하면서 고이의 메시지(정찰제·후불제·맞춤형)를 적극 차용하는 것이 시너지가 있다 — "제주의 고이"라는 포지션.

### 8-3. "고이가 노리지만 아직 못 잡은 영역을 잡는다" 옵션 (장기 시야)

채영이 **고이가 비워둔 영역(재택임종, 무연고 사망, 비수도권 사전 가입자)** 에서 자기 진영을 만든다.

- 장점: 고이와의 직접 충돌 회피. 인구구조 보고서의 미래 시장과 정렬. 채영의 스마트워치 기획안과 연결.
- 단점: 시장이 아직 충분히 크지 않음. 자본·기술 진입 장벽 큼. 단기 현금흐름 약함.
- 채영의 결정 영역: **단기 진입로(8-2)와 병행 가능하나, 자본·시간 분산 위험**. Phase 2 또는 Phase 3 트랙으로 보류.

## 9. 비판적 관찰 — 고이도 비어 있는 자리가 있다

이 부록의 마지막 절은 고이의 약점을 드러내는 데 쓴다. 챔피언이라고 모든 줄에서 강하지는 않다.

### 9-1. 사망 직후 골든타임의 즉시 출동 인프라는 약점

고이의 진입점은 카카오톡 채팅 + 24시간 콜이다. **상담은 빠르지만, 검안의 + 의전팀 + 영구차의 동시 출동을 자동화하는 인프라는 없다.** 채영의 스마트워치 기획안의 "심박 정지 → 자동 출동" 영역은 고이의 영역이 아니다.

### 9-2. 비수도권 운용 인프라는 검증되지 않음

70명 지도사 중 지방 분포는 비공개. 후기의 지도사 이름들도 수도권 활동이 다수로 추정. **제주 출동 시 지도사 이동 비용·시간이 정찰제 패키지에 어떻게 반영되는지가 명확치 않다.** 이게 채영의 제주 진입 여지를 만든다.

### 9-3. 사전 설계의 정밀도는 아직 표준화 단계

100원 상조·고이 퍼스트는 **결제 시점**을 분리한 상품이다. **장례 내용 자체를 사전 설계**하는 단계까지는 가지 않았다. 일본의 슈카츠(終活) 영역 — 사전 의향서, 본인 메시지 영상, 추모 음악 큐레이션, 디지털 유산 정리 — 은 비어 있다.

### 9-4. B2B 영역(장례식장·식장 운영자와의 관계)은 미공개

고이가 39,574건의 의전을 처리하면서 어느 식장과 어떤 관계를 맺고 있는지 공개되지 않는다. **식장이 고이의 영업 깔때기를 막을 가능성**(예: 식장 내부에서 자체 의전 압박)은 잠재 리스크다.

### 9-5. 무연고·8050 영역은 공백

인구구조 보고서가 짚은 미래 시장 — 무연고 사망자, 8050 구조의 경제 능력 없는 자녀 — 에 대한 상품이 없다. 고이의 패키지는 모두 가족이 의사결정자라는 전제 위에 있다.

## 10. 핵심 문장 (한 줄 요약)

> 고이상조는 한국 장례 산업에서 처음으로 "신뢰 인프라"를 자기 사업 모델의 본진으로 삼은 회사다. 정찰제·후불제·100% 환불·70명 검증·실명 후기는 모두 같은 한 가지 사실을 증명하기 위한 도구다 — "이 산업에서 우리가 거짓말하지 않는다." 채영이 진입하려는 시장에는 이미 1위가 있고, 그 1위는 강력하다. 동시에 그 1위가 비워둔 자리(비수도권, 사망 직후 자동 출동, 사전 설계 정밀화, 8050 구조)도 분명히 있다. 채영의 위치 선정은 "고이를 따라잡는다"가 아니라 **"고이가 비워둔 자리에서 채영의 70명 모델을 만든다"**는 방향이 합리적이다.
